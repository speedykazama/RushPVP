/chat = Permite abrir o chat pressionando a tecla T.
/hud = Esse comando suspende a exibição da interface do servidor; ao utilizá-lo novamente, a interface será reativada.
/timeset = Utilizado para alterar o horário e a data. Por exemplo, digite /timeset 12 30 SNOWLIGHT para definir o horário como 12:30 com condições de neve e luz.
/cds = Permite obter as coordenadas da sua localização atual.
/painel = Acessa o painel de grupos, tanto para facções legais quanto ilegais.
/fps = Ajuda a aumentar a taxa de quadros por segundo (frames per second) para uma melhor performance.
/setfuel = Define o nível de combustível do veículo.
/addcar = Adiciona um veículo à sua garagem.
/remcar = Remove um veículo da sua garagem.
/clearinv = Limpa o inventário do jogador.
/clearchest = Limpa o conteúdo de um baú.
/blips = Ativa a exibição de indicadores no mapa (blips).
/god = Concede invulnerabilidade ao jogador.
/food = Impede que o jogador sinta fome ou sede.
/item = Permite ao jogador obter um determinado item.
/nc = Torna o jogador invisível.
/kick = Expulsa um jogador do servidor.
/ban = Bane um jogador do servidor.
/unban = Remove a punição de banimento de um jogador.
/tpcds = Teleporta o jogador para determinadas coordenadas.
/group = Define o grupo de um jogador como legal ou ilegal. Exemplo: /group 1 Admin 1 (não se esqueça de incluir o número 1 após "set").
/ungroup = Remove um jogador de um grupo.
/tptome = Teleporta outro jogador até você.
/tpto = Teleporta você até outro jogador.
/tpway = Teleporta você para um local marcado no mapa.
/hash = Obtém o hash de um veículo novo; necessário para funcionar com a base de dados.
/tuning = Permite ajustar as características do veículo.
/fix = Repara o veículo.
/limpararea = Limpa uma determinada área, útil após explosões.
/announce = Anuncia uma mensagem para todos os jogadores no servidor.
/kickall = Expulsa todos os jogadores do servidor.
/spectate = Permite observar outro jogador.
/dm = Envia mensagens privadas para outros jogadores.
/car = Invoca veículos próximos ao jogador.
/dv = Faz veículos desaparecerem.
